사용 방법

  1. 방법을 선택하여 구글 계정으로 로그인합니다.
  2. 엑셀 파일(.xlsx)을 업로드하거나 구글 스프레드시트 URL을 입력합니다.
  3. 동기화 모드를 선택합니다:
    • 전체 교체: 지정한 날짜 범위의 기존 일정을 모두 삭제하고 새로 추가
    • 증분 업데이트: 제목+날짜가 같은 일정은 업데이트, 새 일정은 추가, 없는 일정은 삭제
  4. 동기화 결과를 확인합니다.

엑셀 파일 형식

다음 열이 필요합니다 (대소문자/한영 구분 없음):

필수 열설명예시
title / 제목일정 제목팀 미팅
start_date / 시작일시작 날짜2026-09-01 또는 09/01/2026
end_date / 종료일종료 날짜2026-09-01

선택적 열: description/내용, location/장소, attendees/참석자(이메일, 콤마/세미콜론 구분), start_time/시작시간, end_time/종료시간
